# Contributing to Kenya Rental Management Research

Thank you for your interest in contributing! This project aims to provide comprehensive, accurate, and useful research for building rental management systems in Kenya.

## How Can You Contribute?

### 1. 📝 Additional Tenancy Agreements
- Share anonymized tenancy agreement templates from other Kenyan counties
- Provide examples from specialized sectors (e.g., Airbnb-style short-term, co-working spaces)
- Document unique clauses or terms you've encountered

### 2. 📊 Data Improvements
- Update market rent rates for 2027+
- Add more sample properties from different Kenyan cities (Kisumu, Nakuru, Eldoret)
- Contribute utility rate data (electricity, water) for different regions
- Add more realistic event scenarios

### 3. 🏗️ Technical Enhancements
- Create SQL schema files for popular databases (PostgreSQL, MySQL, SQLite)
- Develop sample API endpoints based on the lifecycle documentation
- Build Excel templates with pre-built formulas and pivot tables
- Create data visualization dashboards (Tableau, Power BI, Metabase)

### 4. 📖 Documentation
- Translate documents to Swahili (Kiswahili)
- Add more detailed legal analysis or case law references
- Create video tutorials on using the dataset
- Write blog posts or articles referencing this research

### 5. 🐛 Corrections & Updates
- Fix typos or formatting issues
- Update outdated legal references
- Correct data errors or inconsistencies
- Improve clarity of existing documentation

## Contribution Guidelines

### Before You Start
1. Check [existing issues](../../issues) to see if someone is already working on it
2. For major changes, open an issue first to discuss your idea
3. For minor fixes (typos, formatting), feel free to submit a PR directly

### Making Changes
1. **Fork** this repository
2. **Clone** your fork locally
   ```bash
   git clone https://github.com/YOUR-USERNAME/kenya-rental-management-research.git
   ```
3. **Create a branch** for your changes
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** following the guidelines below
5. **Commit** with a clear message
   ```bash
   git commit -m "Add: Brief description of what you added"
   ```
6. **Push** to your fork
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Create a Pull Request** from your fork to this repository

### Code & Data Standards

#### For CSV Data Files
- Use comma-separated format (not semicolon)
- Include headers in the first row
- Use ISO date format (YYYY-MM-DD)
- Ensure all IDs are properly linked (no orphan records)
- Test that files import correctly into Excel

#### For Markdown Documentation
- Use clear, descriptive headings
- Include a table of contents for long documents
- Use code blocks with language tags (```python, ```sql, etc.)
- Add examples where helpful
- Keep line length reasonable (wrap at ~100-120 characters)

#### For Data Privacy
- **Never** include real personal data (names, ID numbers, phone numbers)
- Use realistic but fictional data only
- Anonymize any real tenancy agreements before sharing

### Commit Message Format

Use clear, descriptive commit messages:
- **Add**: `Add new tenancy agreement example for Kisumu`
- **Fix**: `Fix typo in lifecycle documentation`
- **Update**: `Update rent prices for 2027`
- **Improve**: `Improve clarity of deposit refund section`
- **Remove**: `Remove outdated legal reference`

### What We're Looking For

✅ **Good Contributions**:
- Accurate, Kenya-specific information
- Well-documented changes
- Data that follows existing patterns
- Clear, professional writing
- Properly tested code/data

❌ **Please Avoid**:
- Real personal data (use fictional data only)
- Untested code or data
- Plagiarized content
- Changes without explanation
- Breaking existing data relationships

## Review Process

1. Your pull request will be reviewed by maintainers
2. We may ask questions or request changes
3. Once approved, your contribution will be merged
4. You'll be added to the contributors list!
